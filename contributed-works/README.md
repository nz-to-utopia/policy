# Contributed Works

Research, theses, and other works contributed by community members to the NZ to Utopia project.

## How this folder is treated

Files in `contributed-works/` are deliberately quarantined:

- They are part of this repository (the contributor's commit is a permanent, audited record of their decision to publish).
- They do **not** trigger an automatic deploy of nztoutopia.nz. The site's deploy pipeline is configured to ignore changes inside this folder.
- They are **not** rendered as pages on the website. Publication on the live site is a separate, manual decision made by the project maintainers in coordination with the contributor.

This separation lets contributors share their work with the project on terms they control, while giving us a deliberate review step before anything goes live.

## License

Each contributed work is licensed individually by its author. A work's license is set by the `LICENSE` or `NOTICE.md` file in its subfolder, **not** by the top-level repository license (CC BY-SA 4.0). Contributors retain copyright unless they explicitly state otherwise.

If a contributor's subfolder contains no license file, treat the work as "all rights reserved" by default and do not redistribute.

## How to contribute

Contact the project lead (scott@telepathy.co.nz) if you'd like to contribute a work. You'll be added as a collaborator on this repository and can upload your files via the GitHub web UI directly to a folder of your own under `contributed-works/`.

You retain copyright and choose your own license. Your commit will appear in the public history of this repository under your GitHub account, which serves as the auditable record that you - and not the project - chose to publish the work.
